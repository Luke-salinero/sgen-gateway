### Logs Directory

This folder contains developer logs.

Each contributor creates their own subdirectory and maintains their personal log within it.  
These logs help track progress, surface challenges, and build a public record of growth over time.

---

 Structure

```

/logs/  
├── ContributorA/  
│ └── dev-log.md  
├── ContributorB/  
│ └── dev-log.md  
└── README.md

````

- Each subfolder is named after the contributor (`/logs/<name>/`).
- Within that folder, contributors maintain their `dev-log.md`.

---

### Purpose

- Encourage thoughtful reflection on daily progress.
- Improve communication by surfacing blockers and learnings.
- Build a transparent, human-centered developer story.
- Serve as a living portfolio of developer mindset and growth.

---

### Usage

Contributors should:
- Add one entry per workday to their `dev-log.md` file.
- Use clear markdown formatting and headings.
- Commit updates as part of their daily pull request.

Example entry:
```markdown
## Dec 10, 2025
- ✅ Implemented file parser and added test cases.
- ❓ Struggled with path handling on Windows.
- 🎓 Learned about `os.path.join` and `Pathlib`.
````

---

These logs are public — be honest, but write with clarity and self-respect.
